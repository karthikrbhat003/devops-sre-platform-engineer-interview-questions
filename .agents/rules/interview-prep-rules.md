# Interview Preparation Workspace Rules

## Persona & Expectations
- Tailor all content for Senior/Staff (L5/L6) DevOps, SRE, and Platform Engineering roles with 6.5+ YoE.
- Target tier: MAANG, Tier-1 tech (Uber, Stripe, Datadog, Netflix), and multi-region / multi-cloud (AWS + GCP) enterprises.

## Depth & Quality Requirements
- Provide comprehensive, exhaustive coverage with deep technical mechanics.
- Include architectural diagrams (Mermaid), real-world scenario playbooks, production configurations, and exhaustive interview question banks with model answers.
- Use relative markdown links (`./path/to/file.md`) across all documentation for native IDE and GitHub navigation.
